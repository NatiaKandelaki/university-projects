# university-projects
A collection of projects and coursework completed during my Bachelor's degree in Electronic and Computer Engineering.
1. Metal Detector - Analog Electronics, Electromagnetic Detection
2. Burglar Alarm System - Analog Electronics, Sensors, Comparators 
3. Temperature Monitoring & Control - ATtiny13, ADC, Thermistor, Relay, Embedded C 
4. Medication Reminder - ATmega168, I²C, RTC, EEPROM, LCD, Keypad 
5. Lie Detector - ATmega168, PPG, GSR, Signal Conditioning, MATLAB
6. Password Guess Game - FPGA, VHDL, Seven-Segment Display
   
These projects demonstrate my progression from fundamental electronic circuits to microcontroller-based embedded systems and programmable digital hardware.
